# D4LF v10.0.4-koKR-build04.13-preview

이 폴더는 Diablo IV 한국어 클라이언트에서 D4LF를 실행하기 위한 소스 배포본입니다. 기존 D4LF의 영문 내부 ID와 프로필 형식은 유지하고, 한국어 클라이언트의 TTS 문자열과 표시명을 연결합니다.

## 빠른 실행

1. 이 폴더를 쓰기 가능한 위치에 둡니다.
2. `D4LF-koKR-start.bat`를 더블클릭합니다.
3. 최초 실행에서는 필요한 Python 실행 환경과 패키지를 자동으로 설치하므로 잠시 기다립니다.
4. D4LF 창이 열리면 프로필을 가져오거나 기존 프로필을 활성화합니다. 대시보드 왼쪽에서 프로필을 검색하고, 오른쪽의 `착용 장비` 탭에서 스캔 결과를 확인합니다. 단축키는 `키보드 단축키` 탭에 있습니다. `F11`은 소지품 전용, `Alt+F11`은 보관함 전용입니다. 보관함 필터는 보관함을 연 상태에서 사용합니다. 가운데 경계선을 드래그해 영역 너비를 조절할 수 있습니다.

## Windows 단독 실행 ZIP 만들기

Windows 개발 환경에서는 아래 명령으로 Python 설치 없이 실행되는 ZIP을 생성할 수 있습니다.

```powershell
uv sync --group dev
uv run python build_windows_release.py
```

ZIP은 `dist-win-portable` 폴더에 만들어집니다. 압축을 푼 뒤 `D4LF-koKR-portable.bat`를 실행하세요. 이 배포본은 PyInstaller EXE가 아니라 `runtime` 폴더에 포함된 Windows용 Python 실행환경으로 동작합니다. 사용자 PC에 Python을 따로 설치할 필요는 없습니다. Diablo IV TTS 연결은 최초 한 번 `tts\install_dll.cmd`를 관리자 권한으로 실행해야 합니다. 앱과 리소스는 압축을 푼 폴더에서 실행하며, 프로필과 설정은 기존처럼 `%USERPROFILE%\.d4lf`에 보관됩니다.

실행 BAT는 `%USERPROFILE%\.d4lf\params.ini`의 언어를 자동으로 `koKR`로 설정합니다. 이후에도 항상 `D4LF-koKR-start.bat`로 실행하면 됩니다.

한국어 모드에서는 대시보드, 상태 표시, 설정 창, 프로필 편집기, 아이템/옵션/위상/인장/공물 편집 대화상자와 프로필 가져오기 화면의 UI가 한국어로 표시됩니다. 내부 설정 키와 프로필 데이터는 원본 D4LF 호환성을 위해 영문 ID를 유지합니다. 언어 변경 또는 패치 업데이트 후에는 실행 중인 D4LF를 완전히 종료하고 다시 실행해야 UI 언어가 적용됩니다.

## TTS 설치

D4LF는 Diablo IV의 화면 읽기 TTS 정보를 사용합니다. 최초 한 번 다음 작업이 필요합니다.

1. `tts\install_dll.cmd`를 관리자 권한으로 실행합니다.
2. Diablo IV 설치 경로를 입력합니다.
3. 인증서 설치 요청이 나오면 허용합니다.
4. Diablo IV를 다시 시작합니다.

정상 연결되면 D4LF 로그에 `TTS client connected`가 표시됩니다.

## Diablo IV 설정

- 게임 언어: 한국어
- 고급 툴팁 정보: 켜기
- 화면 읽기 기능: 켜기
- 타사 화면 읽기 프로그램: 켜기
- 글꼴 크기: 작게 또는 중간
- HDR: 끄기

기본 필터 실행 단축키는 `F11`입니다.

## 옵션 기준값 입력

- `실제 수치`: 게임 툴팁에 표시된 숫자를 그대로 비교합니다. `극대화 확률 +5.9%`는 `5.9`, `최대 생명력 +2,703`은 `2703`을 입력합니다. 비워 두면 수치 하한을 적용하지 않습니다.
- `범위 %`: 해당 옵션의 최소~최대 범위 안에서 얼마나 높은 값인지 비교합니다. `80`은 가능한 범위의 80% 이상이라는 뜻이며, 게임 TTS에 범위가 없으면 통과하지 않습니다.
- 두 모드는 같은 옵션에 동시에 적용되지 않습니다. `%`가 적힌 실제 옵션이라도 툴팁 숫자 자체를 기준으로 하고 싶으면 `실제 수치`를 선택합니다.

## 착용 장비 확인

1. Diablo IV에서 캐릭터 장비창을 엽니다.
2. D4LF 대시보드 오른쪽의 `착용 장비 스캔`을 누릅니다.
3. D4LF가 게임 창으로 돌아가 착용 슬롯을 순서대로 확인합니다. 약 30초가 걸릴 수 있습니다.
4. 대시보드의 `착용 장비 상태`에서 부위별 결과를 확인합니다.

프로필 선택 메뉴에서 Maxroll 가이드의 `시작`, `중간`, `엔드`, `푸쉬` 프로필을 선택하면 저장된 단계별 목표 차이를 확인할 수 있습니다. 장비는 한 번만 스캔하면 현재 읽은 장비를 각 단계 목표에 각각 대조합니다. 프로필 대상 외 장비와 읽지 못한 슬롯은 완료 수에 섞지 않고 별도로 표시합니다.

`완성`은 프로필에 저장된 해당 부위의 목표 옵션과 조건을 모두 충족한 상태입니다. `보완 필요`에는 부족한 옵션이 표시됩니다. 아이템 툴팁을 받지 못한 슬롯은 `확인 안 됨`으로 남으며 완료로 간주하지 않습니다. 반지처럼 같은 종류가 2개인 경우 각각 다른 프로필 목표에 대응시킵니다.

스캔은 기존 D4LF TTS와 장비 슬롯 좌표를 사용합니다. 현재 게임을 직접 조작하는 기능이므로 게임에서 한 번 확인해야 하며, 위치나 화면 배율에 따라 `확인 안 됨`이 생기면 활동 로그를 함께 확인해 주세요. 결과는 이번 실행 중 대시보드에만 보관되며 재실행 후 다시 스캔합니다.

같은 TTS 아이템 내용이 다른 착용 칸에서 다시 들어오면 이전 칸의 음성이 늦게 도착한 것일 수 있어 `확인 안 됨`으로 표시합니다. 실제로 동일한 내용의 장비 두 개를 착용한 경우에도 보수적으로 이렇게 표시될 수 있습니다. 프로필 편집 화면의 `무기`는 기존 프로필의 `Mace` 항목을 보기 쉽게 표시한 이름이며, 저장된 무기 종류를 자동으로 바꾸지는 않습니다.

상급 옵션은 TTS의 수치가 최대 범위를 넘었다는 이유만으로 추정하지 않습니다. 화면에서 옵션 표식의 모든 행이 안정적으로 대응할 때만 상급으로 판독하며, 대응하지 못하면 기존 TTS 판독 결과를 유지합니다. 빨간 테두리가 나오면 로그의 `greater affixes 0/1`처럼 조건별 불일치 이유를 확인하세요.

스캔 결과에는 읽은 아이템 이름과 칸 번호가 표시됩니다. 장화·투구·가슴 방어구처럼 한 개만 착용할 수 있는 종류가 두 번째로 감지되면 TTS가 다른 칸에서 늦게 도착한 것으로 보고 `확인 안 됨`으로 남깁니다. 스캔 로그에도 칸 좌표와 판정 내용을 기록합니다.

## 판정 색상

- 초록색 전체 테두리: 활성 프로필의 아이템 조건과 일치
- 초록색 옵션 표시: 프로필에서 선택한 개별 옵션과 일치
- 빨간색 전체 테두리: 어떤 활성 프로필 조건과도 일치하지 않음
- 주황색: 위상/힘의 전서 업그레이드 대상

한국어 모드에서는 판정 로그에도 `지능`, `최대 생명력`, `이동 속도`처럼 게임의 한국어 표시명이 출력됩니다. 프로필 파일에는 호환성을 위해 `intelligence`, `maximum_life`, `movement_speed` 등의 기존 내부 ID가 그대로 저장됩니다.

## 기존 프로필

프로필과 설정은 다음 폴더에 저장되므로 D4LF 폴더를 바꾸어도 유지됩니다.

```text
C:\Users\<사용자명>\.d4lf
```

한국어 패치는 영문 내부 ID를 유지하므로 기존 영문 프로필을 그대로 사용할 수 있습니다. `affix intelligence does not exist` 또는 `affixPool affix damage does not exist` 오류가 발생하지 않도록 한국어 데이터에 영문 기준 키를 모두 보존합니다.

### 빨간 테두리 원인 확인

빨간 테두리 아이템을 올린 뒤 활동 로그에서 `Profile miss`를 찾으면 프로필 탈락 원인을 확인할 수 있습니다.

```text
Profile miss ...: affixes matched 1/3; item=['intelligence', 'critical_strike_chance']; required=['vulnerable_damage_multiplier', 'resource_cost_reduction', 'critical_strike_chance', 'attack_speed']
```

이 경우 프로그램 오류가 아니라 프로필의 최소 옵션 개수를 충족하지 못한 것입니다. `Parsed item based on TTS: None`이면 판정 이전의 TTS 파싱 문제이므로 해당 로그의 원문을 함께 확인합니다.

## 문제 해결

### 프로필이 로딩되지 않을 때

최신 파일이 적용됐는지 확인하고 `D4LF-koKR-start.bat`를 다시 실행합니다. 정상 로그에는 다음과 같이 활성 프로필 이름과 필터 종류가 표시됩니다.

```text
Loading profile <프로필 이름>: Affixes AspectUpgrades Seals Charms Tributes Paragon
```

### 마우스는 움직이지만 아이템을 판정하지 않을 때

로그에 `Attempt ... parse item based on TTS: None`이 표시되면 한국어 TTS 아이템 구간을 찾지 못한 것입니다. 이 배포본은 한국어 `마우스 버튼` 경계와 `선조/일반/마법/희귀/전설/고유/신화/세트` 메타데이터를 인식합니다. 실행 중인 D4LF를 모두 종료한 뒤 `D4LF-koKR-start.bat`로 다시 시작해야 변경된 수신기가 적용됩니다.

빨간 테두리만 표시되던 이전 버전은 한국어 TTS 옵션을 영문 키 목록에서 직접 찾는 문제가 있었습니다. 현재 버전은 한국어 표시명을 먼저 찾은 뒤 기존 영문 내부 ID로 변환합니다. 업데이트 후에는 반드시 실행 중인 D4LF 창과 검은색 실행 창을 모두 닫고 다시 시작하세요.

### 고유 아이템이 비교되지 않을 때

한국어 툴팁의 `요구 레벨 ... 고유 장착` 문장은 아이템 등급 줄이 아닙니다. 이전 패치는 이 문장을 새 아이템 시작점으로 잘못 인식해 실제 이름과 옵션을 버릴 수 있었습니다. 현재 버전은 `선조 고유 부적`, `고유 투구`처럼 유효한 등급+아이템 종류 줄만 시작점으로 사용하며, `부적`, `봉인`, `룬`도 한국어 아이템 종류로 인식합니다. 예를 들어 `인검`, `무덤방랑자의 손`, `뼈의 맹약`은 각각 기존 영문 내부 ID `in-geom`, `gravewalkers_hand`, `pact_of_bone`으로 변환됩니다.

### TTS 연결이 안 될 때

- 로그에 `D4LF IS ALREADY RUNNING`이 나오면 모든 D4LF 창과 검은 실행 창을 닫고 BAT를 한 번만 실행합니다.
- `tts\install_dll.cmd`를 관리자 권한으로 다시 실행합니다.
- Diablo IV와 Battle.net 또는 Steam을 완전히 종료한 뒤 다시 실행합니다.
- 게임의 화면 읽기 및 타사 화면 읽기 옵션을 확인합니다.

### 설정 파일 오류로 시작되지 않을 때

`%USERPROFILE%\.d4lf\params.ini`를 다른 이름으로 백업한 뒤 `D4LF-koKR-start.bat`를 다시 실행합니다. 새 설정 파일이 자동 생성됩니다.

## 버전

### 옵션 비교와 편집 안정성

- 옵션 검색 도중 입력이 불완전해도 마지막으로 선택한 옵션 ID를 유지합니다.
- 동일한 표시명의 옵션이 있어도 기존 ID를 다른 ID로 자동 변경하지 않습니다.
- 반지 옵션이 3개 중 2개 일치하면 로그에 `candidate matches 2/3`으로 표시합니다. 최소 개수 또는 상급 조건에 미달한 아이템은 계속 불일치로 판정합니다.
- 다른 장비 유형을 건너뛴 로그는 DEBUG에서 확인할 수 있습니다.
- 수정 적용 후 실행 중인 D4LF를 종료하고 BAT로 다시 실행해야 합니다.

- D4LF 기준 버전: `10.0.4`
- 한국어 빌드: `koKR-build04.12-preview`
- 지원 언어: `enUS`, `koKR`
- 실행 방식: `D4LF-koKR-start.bat`
